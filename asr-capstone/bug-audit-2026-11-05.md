# Bug audit, 5 November 2026

Five read-only subagents each audited one part of the project: scoring and the reported
numbers, the failure searches and judges, the website builders, the pages in a browser, and
the transcription machinery with the results on disk. None of this was fixed unless it says
so. The published site and the midterm notes still carry the numbers below.

**Checked** means the main session confirmed it itself, against the code and data, separately
from the auditor. Everything else is the auditor's report: they ran most of it, but nobody
repeated it. Nobody listened to any audio, and nothing ran on the GPU or the real claude.ai.

The auditors' scripts and screenshots were left in the session's scratchpad, which is temporary.

## Pages that don't work properly

1. Unticking an engine doesn't hide its line, because `.compare-line`'s `display: grid` beats
   `[hidden]`. J/K then skip that engine's errors while the line stays on screen.
2. Data page: pressing Stop before a clip has loaded starts it anyway, and it never stops
   (`data.html:164-167`).
3. Data page: the "(empty)" filter does nothing, so you can't list rows Qwen hasn't read
   (`data.html:204-205`).
4. After touching the position slider it freezes during play, and the arrow keys jump backwards
   (`explorer.js:548`).
5. J, K and the arrows stop working after using a checkbox or menu; Space on a panel heading
   plays audio instead of opening it (`explorer.js:590, 592`).
6. A jump lands under the sticky player, worst on a phone (`explorer.css:62`).
7. Smaller: card words stay lit after a clip ends; no Stop on cards; the no-audio strip marker
   doesn't move; the focused button is lost after sorting or "Next 50"; a quick return can draw
   a recording twice; the list's sort is lost on return.

The browser checkers pass with all of these present. They never untick an engine, press Stop,
or use the slider, and they listen only for uncaught script errors.

## Machinery: hasn't damaged results yet, could later

- A truncated or wrong download is accepted (`corpus/fetch.py:78-90`). All 1,037 MP3s on disk
  look sound, by header and size only.
- Re-transcribing a recording keeps its old score, and 646 transcripts in four `-reread` folders
  have no ledger line, so a queue row naming one would redo them all (`runner.py:107`).
- The default run folder is the superseded one (`cli.py:51`, `store.py:224`); re-scoring one
  engine deletes another's rows in a shared table (`store.py:176`).
- `run_qwen_judge.ps1` could mark cases invalid if Ollama keeps failing, and the loop would
  carry on. Recoverable with `--redo-invalid`; 0 invalid rows so far.
- The supervisor can kill healthy Qwen3 or Whisper work on USB-C power (`supervisor.md:146-148`).
- `judge_compare.py` no longer runs (`KeyError: 'f00201'`); the README's table can't be rebuilt
  by it, though the rows the auditor compared match.
- `triangulate.py` picks the wrong Parakeet run by name; `check_silences.py --limit 5` overwrites
  the whole table; a torn ledger line can stop a restart; no model revision is recorded.
